# Changelog

## 1.4.0

- Fold the nearest enclosing list item, including nested bullets, numbered lists, and task lists.
- Restore independent cursor positions for list parents and headings.
- Add Source mode and Live Preview integration tests for lists.

## 1.3.0

First public release.

- Smart toggle fold targets the containing heading from body text.
- Restore a separate cursor position for each heading when unfolding.
- Keep independent bookmarks for nested headings and open files.
- Preserve bookmarks across tab switches and file renames.
- Clear file memory when its last tab closes.
- Leave built-in commands and hotkey assignments unchanged.
